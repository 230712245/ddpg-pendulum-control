# DDPG Pendulum Control

An advanced deep reinforcement learning project implementing Deep Deterministic Policy Gradient (DDPG) for continuous control in the Inverted Pendulum environment.

## Features
- Deep Deterministic Policy Gradient (DDPG)
- Actor-Critic architecture
- Continuous action space learning
- Experience Replay Buffer
- Target Network stabilization
- Soft target updates using tau
- Ornstein-Uhlenbeck exploration noise
- Bellman equation optimization
- TensorFlow GradientTape training
- Reinforcement learning for pendulum balancing

## Files
- `ddpg_pendulum_control.py` → Python implementation
- `ddpg_pendulum_control.ipynb` → Jupyter Notebook

## Technologies
- Python
- TensorFlow
- Keras
- Gymnasium
- NumPy
- Matplotlib
- Jupyter Notebook

## Description
This project was created to learn advanced deep reinforcement learning techniques using the DDPG algorithm for solving continuous control problems in the Inverted Pendulum environment.
